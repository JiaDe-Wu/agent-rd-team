# Larkspur Outfitters internal web pages: layout

| Path | What it is |
|---|---|
| `server/routes/` | The API |
| `server/data/` | Data (from the knowledge base, copied as it is) |
| `web/pages/` | Pages: one `<page name>.js` each, registered in `index.js` |
| `web/styles/` | Styles: `tokens.css` brand variables, `base.css` site-wide components, and one `<page name>.css` per page |
| `web/motion/` | Brand motion |
| `deploy/` | Deployment configuration |
| `tests/` | Tests; `tests/enterprise/` holds the checks the company issues |
| `docs/aidlc/` | What each stage produces |
