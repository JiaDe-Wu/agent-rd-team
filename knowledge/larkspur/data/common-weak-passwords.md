# Common weak passwords

The list Security maintains: 45 entries, used by the Account Security Standard ACC-2. The comparison ignores case. The list includes passwords built from the company and product names (larkspur123, campfire1 and so on) because attackers try those first.

**The full list is one JSON file: `~/workplace/knowledge/larkspur/data/weak-passwords.json`** (an array of strings). When you write code, put the contents of this file into a constant, verbatim; do not add or remove entries.
